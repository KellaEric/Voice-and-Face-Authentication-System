# Voice + Face Authentication System

An accessible authentication system for visually-impaired users, combining voice and face recognition with anti-spoofing measures.

## Features

- **Dual-Factor Authentication**: Voice + Face biometric verification
- **Accessibility First**: Audio-guided prompts, headphone compatibility
- **Anti-Spoofing**: Liveness detection, random digit challenges
- **Template Security**: No raw biometric data storage
- **Streamlit UI**: User-friendly web interface
